# Smart Task Tracker

Минимальный CLI-прототип умного трекера задач. Принимает список задач в JSON и
возвращает либо нормализованный список, либо отсортированный план с приоритетами
и скорингом.

## Формат входных данных

```json
[
  {
    "title": "Подготовить презентацию",
    "importance": 5,
    "urgency": 4,
    "time_hours": 3,
    "energy": 4,
    "deadline": "2024-10-01",
    "order": 2,
    "depends_on": ["Собрать материалы"]
  }
]
```

Поля:
- `importance`, `urgency`, `energy` — целые числа от 1 до 5.
- `time_hours` — длительность задачи в часах.
- `deadline` — необязательная дата в формате `YYYY-MM-DD`.
- `order` — необязательный пользовательский порядок (целое число).
- `depends_on` — список зависимостей (названия других задач).

## Запуск

```bash
python -m smart_task_tracker.cli path/to/tasks.json
```

Вывести нормализованный список:

```bash
python -m smart_task_tracker.cli path/to/tasks.json --output normalized
```

Вывести таблицу ранжирования:

```bash
python -m smart_task_tracker.cli path/to/tasks.json --output table
```

Вывести план на день:

```bash
python -m smart_task_tracker.cli path/to/tasks.json --output schedule
```

## Как считаем приоритет

Формула:

```
приоритет = срочность + важность + дедлайн + мой порядок - штраф за длительность - штраф за энергию
```

Правила интерпретации:
- если дедлайн сегодня/завтра — повышаем бонус к срочности;
- задачи до 25 минут получают бонус (их легко закрывать);
- тяжёлые задачи (`energy` 4-5) планируйте на утро/день, лёгкие — на вечер.
